# 图标

CodexGauge 使用「暖白底＋橙金阶梯刻度」图标。

- `AppIcon.png`：图标源图，外部浅灰展示底色一并保留。
- `AppIcon.icns`：由该原图转换的 macOS 图标，含 16、32、64、128、256、512、1024 像素表示。
- 重新生成：在项目根目录运行 `bash scripts/generate-app-icon.sh`。

`scripts/build-anchored-quota-button-a1-c1.sh` 在封装生产 `QuotaButton.app` 时复制 `.icns` 并写入 `CFBundleIconFile`，随后签名；缺少图标时停止构建。模拟按钮、模拟宿主和历史候选不变。

## 侧栏额度按钮

2026-11-02 用户确认「额度环＋三级刻度」单色设计。2026-11-06 第108号将外圈改为完整圆环，并以当前 snapshot 的5h剩余比例显示顺时针进度。第109号将中心三条线替换为5h剩余数字：居中、无百分号，使用详情页相同的取整及 `<1`/`>99` 边界格式；unknown/非法/无 snapshot 显示破折号。辅助文字保留精确百分比和“上次记录，待更新”语义。

`SidebarQuotaIcon.svg` 是24 × 24坐标系的100%静态示例：浅色完整轨道为底层，深色完整圈表示100%，中心显示“100”。运行时由 `Sources/QuotaSidebarGlyph.swift` 绘制：弧长使用有效5h剩余 raw Double 百分比，中心数字按详情格式去掉百分号，显示取整后的数值；数字的格式化不改变圆环的精确比例。SVG仅展示满额静态情况，不代表运行时恒定满额。

36 pt渲染画布、1.8 pt圆头描边、44 pt点击区域以及18/24环直径保持；实际可见轮廓约28.8 pt。
